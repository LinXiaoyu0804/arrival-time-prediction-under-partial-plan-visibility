# Source data

`work_experiments/planned_actual_v1/raw/routes_performance.xlsx` is an exact copy of the public Mendeley Data release:

- Title: *Last-mile delivery route deviations dataset: planned vs. actual routes*
- Version: 1
- DOI: <https://doi.org/10.17632/kkwgfvmtxn.1>
- License: CC BY 4.0
- SHA-256: `8f17d15e189c99a34f2446daeaaf1a65d1e79045a94c4d3c452391c96d9cee00`

The `partitions/` files are deterministic analysis partitions derived from that workbook. The `audit/` directory records provenance, field definitions, route audits, split manifests, and source hashes. No private operational data were added.
